Aplicação web oficial da **Associação Comunitária Melhor Idade**, desenvolvida para promover a convivência, valorização, saúde, cultura e integração social da melhor idade.

O portal foi projetado com base em princípios modernos de experiência do usuário, design afetivo e acessibilidade inclusiva, conectando associados, familiares, diretoria e empresas apoiadoras da comunidade.


---

## 💻 Sobre o Projeto Web

A plataforma é um ecossistema completo pensado para atender com excelência tanto o público idoso e seus familiares quanto a equipe de coordenação comunitária:

### 1. 🏠 Página Inicial (`Início`)
- **Acolhimento Institucional:** Mensagem calorosa de boas-vindas com foco em dignidade, afeto e integração.
- **Próximos Encontros:** Destaque dos eventos e atividades programadas para os próximos dias da semana.
- **Resumo da Trajetória:** Pílula histórica apresentando a semente da Associação.
- **Momentos Recentes:** Mosaico fotográfico das tardes mais felizes com abertura interativa em tela cheia.
- **Carrossel de Patrocinadores:** Vitrine animada com logos e nomes das empresas e comércios locais que financiam e apoiam as atividades da Associação, incluindo card interativo para adesão de novos patrocinadores.

### 2. 📜 Nossa História (`Nossa História`)
- **Linha do Tempo Ilustrada:** Narrativa com marcos históricos essenciais da fundação à conquista da sede própria.
- **Desfecho com Propósito:** Card de apelo comunitário *"Ajude-nos a manter essa chama acesa"*, convidando visitantes sensibilizados a contribuir com doações diretas.

### 3. 💃 Atividades Diárias (`Atividades`)
- **Catálogo de Oficinas:** Apresentação detalhada das atividades regulares (*Forró da Melhor Idade*, *Canto & Coral*, *Viagens & Passeios*, *Rainha da Melhor Idade*, *Oficinas de Artesanato*, *Festas Temáticas*).
- **Modal de Horários:** Consulta rápida de dias, horários, locais, professores responsáveis e recomendações de vestuário/conforto.

### 4. 📅 Calendário de Eventos (`Calendário`)
- **Programação Mensal Clara:** Interface com leitura facilitada, exibição dos dias, horários e locais.
- **Filtros por Categoria:** Pílulas temáticas (*Música*, *Coral*, *Lazer*, *Artes*, *Saúde*).
- **Destaques do Mês:** Painel fixo com os encontros imperdíveis de cada mês.

### 5. 📸 Álbum de Lembranças (`Galeria de Fotos`)
- **Acervo Visual da Comunidade:** Categorização por momentos (*Forró*, *Coral*, *Viagens*, *Celebrações*).
- **Visualizador Ampliado (Lightbox):** Modal imersivo com fotos em alta resolução, carrossel de miniaturas, legendas e atalhos de teclado (setas e `ESC`).

### 6. 🤝 Doações e Apoio Empresarial
- **Doação via PIX:** Chave PIX oficial com botão de cópia rápida, QR Code, dados bancários e valores sugeridos com impacto social direto (ex: lanche comunitário, material de oficina, passeios culturais).
- **Apoio para Empresas (PJ):** Formulário direto de cadastro e contato para marcas que desejam patrocinar e estampar sua identidade visual no carrossel da página inicial.

### 7. 🛡️ Painel Administrativo Completo (`Área do Administrador`)
- Ambiente restrito com autenticação para a equipe de gestão da Associação.
- **Visão Geral:** Métricas em tempo real de associados, eventos, lembranças e patrocinadores cadastrados.
- **Gestão do Álbum de Lembranças:** Cadastro, edição e exclusão de memórias fotográficas com upload e suporte a múltiplas imagens.
- **Gestão do Calendário:** Agendamento, alteração de datas, horários e definição de destaques.
- **Gestão de Patrocinadores:** Cadastro de empresas com upload de logo do computador ou link da web, categorias de patrocínio, link do site e status ativo/oculto.
- **Configurações Institucionais:** Edição de dados de contato, endereço e chave PIX com sincronização instantânea.

### 8. ♿ Acessibilidade Integrada
- **Controle de Tamanho de Fonte:** Modos Normal, Aumentado (A+) e Extragrande (A++) para máxima legibilidade.
- **Alto Contraste:** Alternância para esquema de cores com alto contraste, reduzindo o cansaço visual.
- **Leitor de Texto por Voz:** Síntese de fala em português para apoio a associados com baixa visão.

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/):** Componentização declarativa, gerenciamento de estado via Context API e hooks modernos.
- **[Vite](https://vitejs.dev/):** Build tool ultrarrápida com Hot Module Replacement (HMR).
- **[Lucide React](https://lucide.dev/):** Conjunto consistente e elegante de ícones vetoriais.
- **[Canvas Confetti](https://www.npmjs.com/package/canvas-confetti):** Feedback comemorativo ao interagir com doações e cadastros.
- **[Vanilla CSS]:** Design system responsivo construído com variáveis CSS sem frameworks pesados, garantindo carregamento instantâneo.

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- Gerenciador de pacotes `npm`

### Instalação e Execução

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/luiz5644/associacao_melhor_idade.git
   cd associacao_melhor_idade
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   Abra [http://localhost:5173](http://localhost:5173)

---

## 📦 Scripts Disponíveis

- `npm run dev`: Inicia o ambiente de desenvolvimento local.
- `npm run build`: Gera o pacote otimizado de produção na pasta `dist/`.
- `npm run preview`: Executa localmente o build gerado para validação.
